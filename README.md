# 酒馆书屋独立插件

Gloria · v2.0.4

插件只负责连接阅读器和传送书籍资料，不包含阅读器 HTML。

## 安装

在 SillyTavern 的扩展管理中，使用以下地址安装：

```
https://github.com/gloria-yin/ST-nook-extension
```

已安装的插件可以在酒馆扩展管理中检查更新。插件目录内应有 `manifest.json`、`README.md` 和 `extension` 目录。刷新酒馆后，角色卡的“管理聊天文件”中，“导入聊天”旁会出现“添加书籍”。

## 使用

- 链接版：准备资料后点击“打开在线版并导入”，直接进入 https://gloria-yin.github.io/ST-nook/ ，沿用该网址在当前浏览器中已有的书架。浏览器允许读取剪贴板后，资料会进入“新建书籍”编辑界面。
- 文件版：无需在插件中选择 HTML。准备资料后，选择“生成可复制内容”或“下载备份文件（JSON）”，自行在原 HTML 中接收。

选择聊天、正则和头像，填写书名，点击“准备在线导入”或“准备书籍资料”。

文件版提供两种方式：

1. 生成可复制内容：生成后会显示内容并尝试自动复制。回原 HTML 点击右上角“接收书籍”，或在书架直接按 Ctrl+V。自动复制受限时，可在插件中手动选择并复制。
2. 下载备份文件：下载包含所选聊天、正则、头像和书名的 JSON 备份。在原阅读器的“接收书籍”中点击“选择导入文件”，或通过“新建书籍”中的“恢复备份”选择此 JSON。

链接版点击“打开在线版并导入”后，资料先复制到剪贴板，再直接打开固定在线地址。首次使用时请允许浏览器读取剪贴板；如果未自动进入编辑界面，可以点击“接收书籍”接收或粘贴。

接收后进入“新建书籍”编辑界面，可以调整书名、封面、正则和文件顺序，再点击“生成书籍”保存。接收不会覆盖已有书籍；当前正在编辑未保存的书籍时，会先询问是否替换编辑内容。阅读器原有的完整备份恢复仍可使用。

“打开方式”指浏览器，支持当前浏览器、通过系统协议打开已安装的 Microsoft Edge，或自行使用其他浏览器。普通网页无法调出系统完整的浏览器选择窗口，也不能从酒馆直接打开 `file:///` 本地文件；文件版请从资源管理器打开原 HTML，并在需要时使用系统“打开方式”。

## 更新

刷新酒馆后，添加书籍窗口的标题旁应显示 `v2.0.4`。插件脚本和样式的地址带有版本号，避免继续加载旧缓存。若仍显示旧版，按 Ctrl+F5 强制刷新，并确认更新的是当前酒馆账号的扩展目录。

插件仓库与阅读器仓库独立。若要把本地插件修改上传 GitHub，在此插件目录执行：

```powershell
git add -- manifest.json README.md extension
git commit -m "Update ST Nook extension"
git push origin main
```

聊天资料不会写进 HTML、网址或提交到 GitHub。书籍保存在实际打开的阅读器地址对应的浏览器数据中；不同浏览器、不同地址分别存储。此前 v2.0.2 通过酒馆打开的书架仍属于酒馆站点，可以从旧页面导出完整备份后迁移。
