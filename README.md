# 酒馆书屋独立插件

Gloria · v2.0.10

插件负责整理和传送书籍资料，不包含阅读器 HTML。在线阅读器：https://st-nook.pages.dev/

## 安装

在 SillyTavern 扩展管理中使用以下仓库地址安装或更新：

```
https://github.com/gloria-yin/ST-nook-extension
```

刷新酒馆后，角色卡的“管理聊天文件”中，“导入聊天”旁会出现“添加书籍”。窗口标题应显示 `v2.0.10`；脚本和样式地址带版本号，若仍显示旧版可按 Ctrl+F5。插件目录包含 `manifest.json`、`README.md` 和 `extension` 目录。

## 使用

1. 打开角色聊天，点击“添加书籍”。填写书名，选择聊天、已开启的正则和角色头像。
2. 直接点击底部按钮，无需先准备资料：

- **复制资料**：回原 HTML 或在线阅读器，点击“新建书籍”→“接收书籍”。也可在书架直接按 Ctrl+V。无法自动复制时，资料框才会出现，可手动选中按 Ctrl+C，手机可长按复制。
- **下载备份**：直接生成 JSON，不额外压缩。在阅读器的“新建书籍”→“接收书籍”→“选择导入文件”中选择下载的 JSON，也支持原有“恢复备份”入口。
- **在线导入**：复制后直接打开 https://st-nook.pages.dev/ 的接收界面，不将聊天内容写入网址。

接收窗口会尝试读取剪贴板。允许读取后，返回阅读器可自动检测新的书籍资料并弹出接收窗口，同一份资料在当前标签页不会反复提示。浏览器禁止读取时，请在输入框按 Ctrl+V 或长按粘贴，也可使用 JSON 文件；跨站网页无法绕过浏览器的剪贴板权限。

手机复制会在点击时申请剪贴板写入，再在资料准备完成后写入，避免等待压缩后丢失点击授权。复制被拒绝时不会显示成功；资料保留在窗口中，可再次点击复制或长按资料框复制。超过 40 万字符的手机复制资料建议下载备份导入，避免系统剪贴板截断。在线导入也遵循相同规则。

阅读器 v2.0.16 的接收窗口提供“粘贴”按钮，现有 ST Nook Android APK 会调用原生剪贴板接口；系统长按或输入法粘贴后，再点击“接收书籍”即可导入。

接收后进入“新建书籍”编辑界面，可以调整书名、封面、正则和文件顺序，再点击“生成书籍”保存。已有书籍、批注和阅读进度保留；替换未保存的编辑时需要确认。

普通网页不能直接打开 `file:///` 文件。使用本地 HTML 时，请自行打开原文件再接收。不同浏览器、GitHub Pages、Cloudflare Pages 和本地 HTML 分别存储书架；迁移到新网址前，请从原书架导出完整备份，再到新网址恢复。

聊天资料不会写入 HTML、网址或上传到 GitHub。请勿将导出的书籍备份提交到插件仓库。

## 楼层预览

每份聊天下方可展开“查看楼层”，仅显示 char（角色回复），从第 1 条角色回复开始编号。支持选择楼层、上一层/下一层、末层、输入楼层跳转，以及“复制本层”。用户和系统消息不出现在预览选项中；超过 200 层时分区间选择。显示正则仍使用原始消息位置与深度。导出保留全部已选文件的当前正文，包括用户消息。

手机预览使用只读文本框，支持长按选字和拖动选择范围，不弹出输入键盘。选字时外层列表停止滚动；选中文字后，“复制本层”会变为“复制选中”。

当前聊天已经显示的消息直接读取界面中的文本，包括可读取的美化框架内容；未显示或其他文件的消息按酒馆当前显示正则、Markdown 和显示设置处理。动态美化依赖脚本生成的内容，以原聊天界面实际显示的内容为准。预览不会切换、编辑或保存酒馆聊天，勾选正则只影响要传送的书籍资料。

窗口先显示当前聊天，其他文件名在后台读取，不扫描每份文件的正文。展开时才创建预览、读取聊天；切换楼层复用下拉选项和近期预览结果。点击“刷新”重新读取。预览和导出共用文件读取结果，不必重复下载整份聊天。

历史文件解析、JSON 生成和复制压缩优先在 Web Worker 中完成；不支持时自动使用分批处理。下载与复制复用已生成的资料，修改选择、书名或刷新文件后重新生成。关闭窗口会取消读取与处理。

导出是阅读器书籍资料，保留当前正文、发言人、时间、所选正则和封面，不包含备选 swipe、token 统计、生成参数等阅读器不用的数据，不替代酒馆的完整聊天备份。源聊天不会修改。

## 在终端更新

插件和阅读器分别属于两个 Git 仓库，需要各自提交和推送。在本插件目录运行：

```powershell
git status
git add -- manifest.json README.md extension
git commit -m "Update ST Nook extension"
git push origin main
```

阅读器的 `index.html` 和 `sw.js` 需要在阅读器仓库中更新；请勿放进插件仓库。
