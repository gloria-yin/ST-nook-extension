# 酒馆书屋独立插件

Gloria · v2.0.2

插件只负责连接阅读器和传送书籍资料，不包含阅读器 HTML。

## 安装

在 SillyTavern 的扩展管理中，使用以下地址安装：

```
https://github.com/gloria-yin/ST-nook-extension
```

已安装的插件可以在酒馆扩展管理中检查更新。插件目录内应有 `manifest.json`、`README.md` 和 `extension` 目录。刷新酒馆后，角色卡的“管理聊天文件”中，“导入聊天”旁会出现“添加书籍”。

## 使用

- 链接版：固定加载 https://gloria-yin.github.io/ST-nook/ ，不需要输入网址。
- 文件版：点击“选择 HTML 文件”，选择酒馆书屋 v2.0.2 或更新版本的 index.html，浏览器会记住选择。支持时使用文件句柄读取最新文件；普通文件选择模式下，替换 HTML 后需要重新选择。

选择聊天、正则和头像，填写书名，确认后选择“新标签页”或“独立窗口”。阅读器收到资料后进入“新建书籍”编辑界面，可以调整书名、封面、正则和文件顺序，再点击“生成书籍”保存。

为兼容酒馆的跨窗口隔离，链接版会从固定在线地址读取阅读器程序，再在当前酒馆站点的浏览器环境内打开。所选 HTML 也通过当前酒馆站点打开；聊天资料通过浏览器消息传入，不会写进 HTML 或提交到 GitHub。

书籍保存在当前酒馆站点的浏览器数据中。使用阅读器的完整备份功能，可以搬到直接打开的在线页或本地 HTML。网页中的“打开方式”支持新标签页和独立窗口；系统默认浏览器由浏览器和操作系统控制。
