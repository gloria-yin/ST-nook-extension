# 酒馆书屋独立插件

Gloria · v2.0.5

插件负责整理和传送书籍资料，不包含阅读器 HTML。在线阅读器：https://st-nook.pages.dev/

## 安装

在 SillyTavern 扩展管理中使用以下仓库地址安装或更新：

```
https://github.com/gloria-yin/ST-nook-extension
```

刷新酒馆后，角色卡的“管理聊天文件”中，“导入聊天”旁会出现“添加书籍”。窗口标题应显示 `v2.0.5`；脚本和样式地址带版本号，若仍显示旧版可按 Ctrl+F5。插件目录包含 `manifest.json`、`README.md` 和 `extension` 目录。

## 使用

1. 打开角色聊天，点击“添加书籍”。填写书名，选择聊天、已开启的正则和角色头像。
2. 点击“准备书籍资料”。底部按钮横排显示；无需选择链接版或文件版。
3. 选择以下任意方式导入：

- **复制书籍资料**：回原 HTML 或在线阅读器，点击“新建书籍”→“接收书籍”。也可在书架直接按 Ctrl+V。无法自动复制时，手动选中资料框按 Ctrl+C，手机可长按复制。
- **下载备份文件（JSON）**：在阅读器的“新建书籍”→“接收书籍”→“选择导入文件”中选择下载的 JSON，也支持原有“恢复备份”入口。
- **复制并打开在线阅读器**：复制后直接打开 https://st-nook.pages.dev/ 的接收界面，不将聊天内容写入网址。

接收窗口会尝试读取剪贴板。允许读取后，返回阅读器可自动检测新的书籍资料并弹出接收窗口，同一份资料在当前标签页不会反复提示。浏览器禁止读取时，请在输入框按 Ctrl+V 或长按粘贴，也可使用 JSON 文件；跨站网页无法绕过浏览器的剪贴板权限。

接收后进入“新建书籍”编辑界面，可以调整书名、封面、正则和文件顺序，再点击“生成书籍”保存。已有书籍、批注和阅读进度保留；替换未保存的编辑时需要确认。

普通网页不能直接打开 `file:///` 文件。使用本地 HTML 时，请自行打开原文件再接收。不同浏览器、GitHub Pages、Cloudflare Pages 和本地 HTML 分别存储书架；迁移到新网址前，请从原书架导出完整备份，再到新网址恢复。

聊天资料不会写入 HTML、网址或上传到 GitHub。请勿将导出的书籍备份提交到插件仓库。

## 在终端更新

插件和阅读器分别属于两个 Git 仓库，需要各自提交和推送。在本插件目录运行：

```powershell
git status
git add -- manifest.json README.md extension
git commit -m "Update ST Nook extension"
git push origin main
```

阅读器的 `index.html` 和 `sw.js` 需要在阅读器仓库中更新；请勿放进插件仓库。
